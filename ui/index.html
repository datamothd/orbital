Visual Settings

Explorer Settings

Changing a preference restarts Windows Explorer. Your taskbar and desktop will briefly disappear. Hold Shift while clicking to skip confirmation, or enable Skip confirmation prompts in Settings.
Recommended · Personal preference

Taskbar

Center taskbar icons

Centers taskbar icons. Disable to align them to the left.

Show Task View button

Shows the Task View button on the taskbar. Win+Tab works either way.

Show flashing on taskbar apps

Allows app icons on the taskbar to flash when they need your attention.

Allow Widgets

Allows the widgets board and its taskbar content. Requires administrator access.

Enable taskbar End task

Adds End task to app menus on the taskbar to force-close apps. Unsaved work may be lost.

Desktop

Hide shortcut arrow icon

Hides the arrow overlay on desktop shortcuts. Requires administrator access.

File Explorer · File visibility

Hide known file extensions

Hides extensions for known file types, such as .exe, .txt and .png.

Show hidden files

Shows hidden files, folders and drives.

Hide empty drives
